# 关于本站

这里是 **目南殇** 的个人博客，用来存放学习笔记、工具备忘和偶尔的长文。站点的副标题是「记录学习与思考」——如果某篇文章对你有用，我会很高兴。

## 关于我

昵称 **目南殇**。我喜欢把弄懂的东西写下来：一方面方便以后自己查，另一方面也算是对知识的一次整理。本站观点仅代表个人，若有不严谨之处，欢迎指正。

## 你会在这里看到什么

- 技术相关：命令、配置、踩坑记录等
- 读书笔记或随笔（随写随发，不保证更新频率）

内容以中文为主，力求写得清楚、可检索，而不是堆术语。
